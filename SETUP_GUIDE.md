# 🚀 Пошаговая инструкция по запуску бота

## 📋 Предварительные требования

- Python 3.8 или выше
- Аккаунт в Telegram
- Текстовый редактор (VS Code, PyCharm, Sublime Text и т.д.)

## Шаг 1: Создание бота через BotFather

1. **Откройте Telegram** и найдите бота [@BotFather](https://t.me/botfather)

2. **Отправьте команду** `/newbot`

3. **BotFather спросит имя бота**. Введите, например:
   ```
   My Awesome Quiz Bot
   ```

4. **BotFather спросит username бота** (должен заканчиваться на "bot"):
   ```
   my_awesome_quiz_bot
   ```

5. **Сохраните токен**, который даст BotFather:
   ```
   1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ```
   
   ⚠️ **ВАЖНО**: Не показывайте этот токен никому!

## Шаг 2: Настройка бота (опционально)

### Добавление описания

Отправьте команду `/setdescription` в BotFather и введите:
```
Бот с викториной! Проверьте свои знания, ответив на 15 интересных вопросов с картинками. 
Получите статистику правильных и неправильных ответов!
```

### Добавление информации "О боте"

Отправьте команду `/setabouttext` и введите:
```
🎮 Викторина - бот для проверки знаний
📊 15 вопросов на различные темы
🖼️ Картинки к каждому вопросу
📈 Статистика результатов
```

### Загрузка аватара

1. Отправьте команду `/setuserpic`
2. Загрузите любую картинку (можно скачать из интернета)

### Настройка команд

Отправьте команду `/setcommands` и введите:
```
start - Начать викторину
stats - Показать статистику
restart - Начать заново
help - Помощь
```

## Шаг 3: Установка Python и зависимостей

### Проверка Python

Откройте терминал/командную строку и введите:

```bash
python --version
```

Или:

```bash
python3 --version
```

Должна отобразиться версия Python 3.8 или выше.

### Создание папки проекта

```bash
# Создать папку
mkdir telegram_quiz_bot
cd telegram_quiz_bot
```

### Создание виртуального окружения (рекомендуется)

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

Вы увидите `(venv)` перед строкой в терминале.

### Установка зависимостей

Создайте файл `requirements.txt` со следующим содержимым:
```
python-telegram-bot==20.7
python-dotenv==1.0.0
```

Установите зависимости:
```bash
pip install -r requirements.txt
```

## Шаг 4: Создание файлов проекта

### 4.1. Создайте файл `.env`

**ВАЖНО**: Этот файл содержит ваш токен и не должен попадать на GitHub!

Создайте файл `.env` и добавьте:
```
BOT_TOKEN=ваш_токен_от_BotFather
```

Замените `ваш_токен_от_BotFather` на реальный токен.

### 4.2. Скопируйте остальные файлы

Скопируйте все файлы из проекта:
- `bot.py`
- `config.py`
- `quiz_manager.py`
- `user_manager.py`
- `questions.py`
- `.gitignore`
- `README.md`

## Шаг 5: Запуск бота

### Проверка структуры проекта

Убедитесь, что у вас есть все файлы:

```
telegram_quiz_bot/
├── bot.py
├── config.py
├── quiz_manager.py
├── user_manager.py
├── questions.py
├── requirements.txt
├── .env
├── .gitignore
└── README.md
```

### Запуск

```bash
python bot.py
```

Или на Linux/macOS:
```bash
python3 bot.py
```

Вы должны увидеть:
```
INFO - Starting bot...
```

Это значит, что бот работает! ✅

## Шаг 7: Остановка бота

Чтобы остановить бота, нажмите `Ctrl + C` в терминале.

## 🔧 Решение проблем

### Ошибка: "BOT_TOKEN не найден"

**Решение:**
1. Убедитесь, что файл `.env` создан
2. Проверьте, что в `.env` правильно указан токен
3. Убедитесь, что нет лишних пробелов:
   ```
   BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ```

### Ошибка: "No module named 'telegram'"

**Решение:**
```bash
pip install python-telegram-bot --upgrade
```

### Ошибка: "Conflict: terminated by other getUpdates request"

**Решение:**
Это значит, что бот уже запущен в другом месте. Остановите другие запуски бота.

### Картинки не загружаются

**Причина:** Используются URL из Unsplash, которые требуют интернет-соединения.

**Решение 1:** Проверьте интернет-соединение

**Решение 2:** Замените URL картинок на локальные файлы в `questions.py`:
```python
image_url="images/q1.jpg"  # вместо URL
```

Создайте папку `images` и поместите туда картинки.

### Бот не отвечает

**Проверьте:**
1. Запущен ли бот (смотрите терминал)
2. Правильный ли токен в `.env`
3. Есть ли интернет-соединение
4. Нет ли ошибок в терминале

## 🐛 Отладка

### Включение подробного логирования

В файле `bot.py` измените:
```python

```

На:
```python
level=logging.DEBUG
```

Это покажет больше информации о работе бота.
