# Telegram Quiz Bot - Бот-викторина

## 📋 Описание проекта
Telegram-бот с викториной из 15 вопросов. Каждый вопрос содержит картинку, текст вопроса и варианты ответов. По окончании викторины пользователь получает статистику правильных и неправильных ответов.

## 🏗️ Структура проекта
```
telegram_quiz_bot/
│
├── bot.py                 # Главный файл запуска бота
├── config.py             # Конфигурация и настройки
├── quiz_manager.py       # Класс управления викториной
├── user_manager.py       # Класс управления пользователями
├── questions.py          # Класс с вопросами викторины
├── requirements.txt      # Зависимости проекта
├── .env                  # Переменные окружения (токен бота)
├── .gitignore           # Файлы для игнорирования в git
│
└── images/              # Папка с изображениями для вопросов
    ├── q1.jpg
    ├── q2.jpg
    └── ...
```

## 🚀 Установка и запуск

### 1. Создание бота через BotFather

1. Откройте Telegram и найдите [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot`
3. Введите имя бота (например: "My Quiz Bot")
4. Введите username бота (например: "my_quiz_123_bot")
5. Сохраните полученный токен

### 2. Настройка бота

```
/setdescription - Добавить описание бота
/setabouttext - Добавить информацию "О боте"
/setuserpic - Загрузить аватар бота
/setcommands - Настроить команды:
  start - Начать викторину
  stats - Показать статистику
  restart - Начать заново
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` и добавьте ваш токен:
```
BOT_TOKEN=your_bot_token_here
```

### 5. Запуск бота

```bash
python bot.py
```

## 📚 Функционал бота

- ✅ 15 вопросов с картинками
- ✅ Варианты ответов для каждого вопроса
- ✅ Подсчет правильных и неправильных ответов
- ✅ Статистика по окончании викторины
- ✅ Возможность пройти викторину заново
- ✅ ООП структура с классами

## 🎯 Команды бота

- `/start` - Начать викторину
- `/stats` - Посмотреть текущую статистику
- `/restart` - Начать викторину заново
- `/help` - Помощь
