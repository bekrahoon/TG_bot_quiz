# 📦 Инструкция по загрузке проекта на GitHub

## Шаг 1: Создание репозитория на GitHub

1. Перейдите на [GitHub](https://github.com)
2. Нажмите на кнопку **"New"** (зеленая кнопка справа) или **"+"** → **"New repository"**
3. Заполните данные:
   - **Repository name:** `telegram-quiz-bot`
   - **Description:** `Telegram bot with quiz - 15 questions`
   - **Visibility:** Public или Private (на ваш выбор)
   - ✅ Поставьте галочку **"Add a README file"** (или уберите, если будете использовать свой README)
   - **gitignore template:** Python
4. Нажмите **"Create repository"**

## Шаг 2: Подготовка файлов проекта

1. Создайте папку для проекта на вашем компьютере
2. Поместите все файлы проекта в эту папку:
   ```
   telegram_quiz_bot/
   ├── bot.py
   ├── config.py
   ├── quiz_manager.py
   ├── user_manager.py
   ├── questions.py
   ├── requirements.txt
   ├── .env.example
   ├── .gitignore
   └── README.md
   ```

## Шаг 3: Инициализация Git (если еще не сделано)

Откройте терминал/командную строку в папке проекта:

```bash
# Инициализация Git
git init

# Проверка статуса
git status
```

## Шаг 4: Добавление файлов в Git

```bash
# Добавить все файлы
git add .

# Или добавить файлы по отдельности
git add bot.py
git add config.py
git add quiz_manager.py
git add user_manager.py
git add questions.py
git add requirements.txt
git add .env.example
git add .gitignore
git add README.md

# Проверить, что файлы добавлены
git status
```

## Шаг 5: Создание коммита

```bash
# Создать коммит с описанием
git commit -m "Initial commit: Telegram quiz bot with 15 questions"
```

## Шаг 6: Связывание с GitHub

```bash
# Связать локальный репозиторий с GitHub
# Замените YOUR_USERNAME на ваш username в GitHub
git remote add origin https://github.com/YOUR_USERNAME/telegram-quiz-bot.git

# Проверить удаленный репозиторий
git remote -v
```

## Шаг 7: Загрузка на GitHub

```bash
# Переименовать ветку в main (если нужно)
git branch -M main

# Загрузить код на GitHub
git push -u origin main
```

## Шаг 8: Проверка загрузки

1. Перейдите на страницу вашего репозитория на GitHub
2. Обновите страницу
3. Убедитесь, что все файлы загружены

## 🔐 ВАЖНО: Безопасность

**НЕ ЗАГРУЖАЙТЕ на GitHub:**
- ❌ Файл `.env` с вашим токеном бота
- ❌ Любые приватные ключи и пароли

**ЗАГРУЖАЙТЕ:**
- ✅ Файл `.env.example` (шаблон без реального токена)
- ✅ Файл `.gitignore` (который исключает .env из загрузки)

## 📝 Дополнительные команды Git

```bash
# Проверить статус
git status

# Посмотреть историю коммитов
git log

# Добавить изменения
git add .
git commit -m "Update: описание изменений"
git push

# Обновить локальный репозиторий
git pull
```

## 🎥 Альтернативный способ: GitHub Desktop

Если вы предпочитаете графический интерфейс:

1. Скачайте [GitHub Desktop](https://desktop.github.com/)
2. Установите программу
3. Войдите в свой аккаунт GitHub
4. Нажмите **File** → **Add Local Repository**
5. Выберите папку с проектом
6. Нажмите **Publish repository**
7. Заполните данные и нажмите **Publish**

## 📸 Создание видео работы бота

### Вариант 1: Запись экрана на Windows

1. Нажмите **Win + G** (Xbox Game Bar)
2. Нажмите кнопку записи (круглая кнопка)
3. Откройте Telegram и покажите работу бота
4. Остановите запись
5. Видео сохранится в **C:\Users\ВашеИмя\Videos\Captures**

### Вариант 2: OBS Studio

1. Скачайте [OBS Studio](https://obsproject.com/)
2. Настройте источник записи (экран)
3. Начните запись
4. Покажите работу бота
5. Остановите запись

### Вариант 3: Запись на телефоне

1. Используйте встроенную функцию записи экрана
2. Откройте Telegram
3. Покажите работу бота
4. Остановите запись

### Что показать в видео:

1. ✅ Запуск бота командой `/start`
2. ✅ Прохождение нескольких вопросов (минимум 5-7)
3. ✅ Правильные и неправильные ответы
4. ✅ Статистику командой `/stats`
5. ✅ Завершение викторины с итоговыми результатами
6. ✅ Команду `/restart`
7. ✅ Команду `/help`
